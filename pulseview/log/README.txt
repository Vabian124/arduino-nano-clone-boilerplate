Raw RF pulse logs from Nano D2 (remote Dout).
Each RAW line: edge durations in microseconds (PulseView-style timing list).
DEC/CODE lines: decoded PT2262 value when parse succeeds.

Files:
  both_short_hold_raw.txt  — full serial capture (RAW + DEC + gestures)
  SESSION_SUMMARY.txt      — what was intended vs what events fired
